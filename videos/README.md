# 프로젝트 소개 영상 디렉터리 (videos)

이 디렉터리는 `sj-lab-mapservice` 접속 시 노출되는 인트로 팝업 모달에서 재생할 소개 영상 미디어 파일의 저장소입니다.

## 파일 배치 규격
- **권장 파일명**: `sj-lab-intro.mp4`
- **권장 형식**: MP4 (H.264 비디오 코덱 + AAC 오디오 코덱)
- **권장 해상도**: 1920x1080 (1080p) 또는 1280x720 (720p), 16:9 화면비
- **권장 용량**: 웹 스트리밍 최적화를 위해 10MB ~ 30MB 이하 권장

## 동작 원리
1. `index.html` 내 비디오 태그의 기본 소스는 `videos/sj-lab-intro.mp4`로 지정되어 있습니다.
2. 영상 파일이 디렉터리에 존재하면 모달 팝업 오픈 시 영상 플레이어로 직접 시청할 수 있습니다.
3. 영상 파일이 없거나 로드할 수 없는 환경인 경우, 자동으로 `intro-video-fallback` 안내 카드가 표출되어 사용자에게 시스템 핵심 파이프라인 브리핑을 전달합니다.
