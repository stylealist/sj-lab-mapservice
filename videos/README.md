# 소개 영상 (videos)

접속 시 뜨는 인트로 팝업과 소개 탭에서 재생하는 영상 파일입니다. 원본 화면녹화 4개(QGIS 업로드 · 현장조사 앱 · 웹 내업 처리 · 소개/연락처)를 하나로 편집하고 한글 자막을 넣은 결과물입니다.

## 파일

| 파일 | 길이 | 크기 | 쓰이는 곳 |
|---|---|---|---|
| `intro-summary.mp4` | 1분 05초 | 약 4.3MB | **인트로 팝업 기본 재생** (무음 — 자동재생 정책 대응) |
| `full-demo.mp4` | 6분 10초 | 약 25MB | 팝업의 "전체 소개 영상 보기" (소리 포함) |
| `intro-poster.jpg` | — | — | 요약본 포스터 |
| `full-poster.jpg` | — | — | 전체본 포스터 |

규격: MP4(H.264 + AAC), 1280×720, 30fps, `+faststart`(스트리밍 시작이 빠르도록 moov 앞으로).

## 동작

1. 사이트에 들어오면 팝업이 열리며 **요약본이 음소거로 자동재생**됩니다(브라우저가 막으면 포스터 상태로 대기).
2. 팝업의 **"전체 소개 영상 보기 (6분)"** 를 누르면 같은 플레이어가 `full-demo.mp4`로 바뀌고 소리가 켜집니다(버튼 클릭이 사용자 제스처라 재생이 허용됨).
3. **소개 탭**에는 별도 플레이어를 두지 않습니다(2026-09-28 제거). 탭 상단의 "프로젝트 소개 영상 보기" 버튼이 위 팝업을 다시 엽니다.
4. 영상 로드에 실패하면 팝업은 기존 안내 카드(`intro-video-fallback`)로 대체됩니다.

관련 코드: `index.html`(팝업·소개 탭 마크업), `js/modules/intro-modal.js`, `css/components/intro-modal.css`.

## 교체할 때

같은 파일명으로 덮어쓰면 됩니다. 길이나 구성이 바뀌면 `js/modules/intro-modal.js`의 배지 텍스트("1분 요약" / "전체 6분")와 `index.html`의 버튼 문구("전체 소개 영상 보기 (6분)")도 함께 고치세요.

원본 영상과 편집 스크립트는 저장소에 두지 않습니다(용량). 편집은 ffmpeg으로 ① 1920×1080 캔버스 정규화(세로 영상은 배경 블러 채움) ② 구간 타이틀 카드 ③ ASS 자막 번인 ④ 개인정보 구간 블러 순으로 처리했습니다.

## 주의

- **개인정보**: 현장조사 앱 구간에 담당자명·연락처가 보이는 장면이 있어 해당 구간(4.6초)은 블러 처리했습니다. 영상을 교체할 때도 같은 확인이 필요합니다.
- 용량이 큰 바이너리라 저장소가 무거워집니다. 더 늘어나면 외부 스토리지·CDN이나 YouTube 비공개 임베드로 옮기는 편이 낫습니다.
