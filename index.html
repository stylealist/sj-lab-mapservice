    SJ-LAB 플래그십 GIS 서비스

    현장 점검부터 사무실 조치까지,
    원스톱 공간정보(GIS) 시설물 관리 플랫폼

    SJ 시설물 관리는 현장 모바일 조사원(외업)과 관제실 및 사무국 관리자(내업)의 업무를 실시간으로 연결하는 차세대 클라우드 GIS 웹 서비스입니다. 2,500여 건의 대용량 시설물 데이터를 OGC 표준 기반으로 시각화하고, 공간 클러스터링, 현장 미디어 관제, 인라인 조치 등록, 공공 표준 PDF 보고서 발행까지 엔드투엔드로 완결합니다.

    2,500+
    실시간 시설물 POI
    BBOX 뷰포트 프리패칭 및 최적화 렌더링

    엔드투엔드(End-to-End) 데이터 아키텍처

    Step 1. 현장 외업
    모바일 현장 점검
    infra-manage-app

    QField 기반 모바일 앱으로 현장 조사원이 지오메트리, 파손 상태, 보수 필요 여부, 사진·음성·동영상을 오프라인/온라인으로 수집합니다.

    Step 2. 클라우드 연동
    증분 동기화 엔진
    sj-qfieldsync

    Python 백그라운드 데몬이 30초 주기로 변경 델타 패킷을 감지하여 PostGIS infra_facilities 공간 테이블로 자동 머지합니다.

    Step 3. 공간 API
    고성능 공간 백엔드
    mapservice-rest

    Spring Boot 3 + PostGIS GiST 인덱스 기반으로 뷰포트 BBOX 공간 질의를 초고속 처리하고 표준 GeoJSON 피처 컬렉션을 스트리밍합니다.

    Step 4. 웹 관제
    인터랙티브 웹 관제
    sj-lab-mapservice

    OpenLayers 기반 클러스터링/스파이더링 핀 표출, 멀티미디어 실시간 검토, 내업 인라인 조치 및 공공 서식 PDF 보고서를 원클릭 발행합니다.

    주요 기능 및 엔지니어링 하이라이트

    클러스터링 & Spidering 분산

    대규모 시설물 핀을 지도 축척에 맞게 지능적으로 그룹화하고, geometryFunction 연산으로 UI 목록과 배지 건수를 100% 동기화합니다. 동일 좌표 초근접 지점은 고배율 시 나선형(Spidering)으로 펼쳐 정밀 선택성을 보장합니다.

    현장 멀티미디어 실시간 관제

    현장 조사원이 스마트폰으로 기록한 고화질 사진, 현장 음성(M4A) 녹음, 동영상(MP4)을 브라우저 상세 팝업에서 별도 다운로드 없이 즉시 스트리밍 재생하여 파손 및 결함 현황을 신속히 파악합니다.

    내업 조치 & 표준 PDF 보고서

    보수 필요 시설물에 대해 접수·처리중·완료 등 상태 전환, 조치 내용, 전/후 사진 Canvas 자동 압축 업로드를 지원하며, 1클릭으로 공공기관 표준 서식의 PDF 현장점검 보고서를 즉각 생성·다운로드합니다.

    전국 실시간 교통 CCTV 연계

    국가교통정보센터(ITS) API와 연동하여 전국 고속도로 및 주요 국도 CCTV 위치를 지도 상에 오버레이하고, Hls.js 기반 저지연 스트리밍 엔진을 통해 실시간 도로 및 기상 상황을 동시 모니터링합니다.

    3단계 행정구역 연쇄 필터

    시·도 → 시·군·구 → 읍·면·동으로 이어지는 동적 연쇄 드롭다운을 통해 목적 구역으로 즉각 뷰포트를 이동하고, 키워드 검색 및 보수 필요 여부 라디오 필터와 결합하여 대규모 시설물을 신속히 탐색합니다.

    정밀 공간 측정 도구 & 캡처

    거리, 면적, 반경, 각도 등 공간 분석 인터랙션 도구를 완비하였으며, 브라우저 Canvas 기반 지도 캡처 기능과 VWorld 일반·위성·하이브리드 베이스맵 스위칭을 지원합니다.
